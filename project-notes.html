SylClips

Personal project · ongoing

Try the public demo ↗Companion API source ↗Portfolio overview ↗

From long footage to reviewable decisions.

The project analyzes video, identifies candidate clip boundaries and produces structured short-form plans that can be reviewed before rendering.

PROBLEM

Turn long video into clip decisions that a person can inspect before rendering.

MY CONTRIBUTION

Connected model proposals to validation, review state and a structured plan across TypeScript and FastAPI.

PUBLIC PROOF

Change a fictional cut in the live lab and inspect the resulting plan; read the companion API source.

ENGINEERING DETAIL

MY ROLE

Building the application workflow across TypeScript/Node.js and FastAPI, integrating model outputs with validation and human feedback.

CORE DESIGN

Gemini is the default decision path. Claude is a fallback. Outputs are checked against schemas and project rules before downstream steps.

AGENT

A bounded tool-calling assistant can inspect job state and previews through a limited read-oriented tool set. It does not autonomously publish content.

EXPERIMENTAL ML

A PyTorch boundary classifier is being evaluated as a local option. Hybrid routing and abstention are experimental, separate from the default path.

Public evidence: The interactive lab demonstrates review state and plan generation with invented inputs. Its stateless companion API is public source code; the live page currently uses the static sample dataset. Neither interface runs the private pipeline, real inference or a public video upload. A documentation RAG assistant is in development and is separate from the current video decision path.

03 / FULL-STACK DEMO

NEXO Service Desk

Personal project · fictional cases

Open live demo ↗Portfolio overview ↗

Follow an incident from report to verified fix.

NEXO simulates the technical and functional work of diagnosing and resolving user-reported issues across a full-stack application.

PROBLEM

Make each incident reproducible, traceable and reviewable from intake to resolution.

MY CONTRIBUTION

Built the Angular interface, Java 21/Spring Boot REST API and SQL-backed case history.

PUBLIC PROOF

Try the live demo with fictional incidents; the source repository is private.

ENGINEERING DETAIL

WORKFLOW

Create, search and filter cases; record reproduction steps, expected and observed results, impact, investigation notes and dated history.

DIAGNOSIS

Document a probable origin in the interface, API, backend or database. Selecting a layer requires supporting evidence; the application does not detect the cause automatically.

BACKEND RULES

The API validates case data and requires cause, correction and verification before resolution. SQL queries use JdbcTemplate with parameters.

STACK & DATA

Angular, Java 21, Spring Boot, H2 and SQL. A fictional billing regression uses BigDecimal; its expected total is €49.53.

Scope: This is a personal demonstration inspired by a full-stack job description, not software for Vortech or a client. The public deployment uses in-memory H2, so new incidents may disappear when the service restarts or sleeps.
